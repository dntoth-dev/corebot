# corebot
This is Core Bot, an all-rounder application for any Discord community assisting server staff with server management, moderation and notifications, providing high-quality analytics and server insights, and engaging with members in fun activities.

# License
The project is closed-source, and is intended only for the developer group in *QuantumStrike*.
GitHub is used for tracking changes and collaboration, not for publishing source code.

# Instruction
If you encounter a bug or an error either in the source code or the functionality of the bot, report it immediately to the  [Issues](https://github.com/dntoth-dev/corebot/issues) page of the Repository or send a direct message on Discord to @td.official.
