Privacy Policy

This policy explains how Core operates on Discord and what data it accesses or processes. QuantumStrike is used here as an alias and does not represent a registered legal entity.

Last Updated: August 2, 2026

What This Policy Covers

Core is a Discord bot designed for server moderation, record lookup, and YouTube feed interaction. This policy covers the information Core accesses through Discord and the actions the bot performs, not the data collected by Discord itself.

Data Accessed by Core

Core utilizes a secure Supabase database to persistently store configuration state, server settings, and necessary moderation logging metrics. The bot accesses the following information to operate efficiently:

  • Discord user IDs, usernames, and mentions for command responses
  • Member and guild IDs when performing moderation actions like mute, kick, ban, and unban
  • Audit log entries when the bot is asked to inspect or report records
  • Guild member counts for informational commands
  • YouTube channel metadata and video links via the configured YouTube API key

What Core Does Not Do

Core is intentionally lightweight and does not:

  • store your Discord messages or conversations persistently
  • collect or retain payment, billing, or financial details
  • track you outside of Discord or link your Discord data to external profiles
  • share your Discord credentials, tokens, or personal data with third parties

Security and Tokens

The bot itself uses an environment variable for its Discord bot token. That token is required to authenticate with Discord, but it is not shared or stored in the web application. Keep your token private and never post it publicly.

The bot also relies on optional environment values such as API keys and role IDs to operate, but these are kept in configuration and not displayed to users.

Third-Party Services

Core may interact with the following external services only when configured:

  • YouTube Data API for fetching recent videos from a configured channel
  • Discord API for member, audit log, and moderation actions
  • Supabase for secure, persistent cloud data storage and configuration state management

No other analytics or tracking services are currently integrated into this bot or the site.

User Rights

As a Discord user, you can control your own privacy settings through Discord. You may also request that server administrators remove the bot from a guild or revoke its permissions.

If you believe Core is accessing information incorrectly or you have privacy questions, contact the server owner or the bot support channel.

Need clarification?

This policy reflects the current implementation. If the bot is extended in the future to persist data, this page will be updated accordingly.
